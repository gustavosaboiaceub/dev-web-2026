## 📂 Estrutura do portfólio

O site está dividido nas seguintes seções:

### 1. Início
Apresentação pessoal com nome, descrição, fotografia de perfil e links para redes profissionais.

### 2. Sobre mim
Apresentação da minha trajetória acadêmica, objetivos profissionais e conhecimentos atuais.

### 3. Projetos
Exibição dos projetos desenvolvidos durante minha formação e em atividades pessoais.

### 4. Skills
Apresentação das tecnologias e ferramentas que fazem parte do meu aprendizado.

### 5. Contato
Formulário para facilitar a comunicação, com opções de contato pelo WhatsApp e e-mail.

## 🚀 Projetos desenvolvidos

### 1. To-do List
Projeto de uma lista de tarefas, com o objetivo de organizar atividades e facilitar o acompanhamento de tarefas.

### 2. Love, Death & Robots
Desenvolvimento de um site temático inspirado na série *Love, Death & Robots*, utilizando HTML5 e CSS3.

### 3. Banco de Dados MySQL
Projeto acadêmico envolvendo criação e manipulação de banco de dados, utilizando comandos SQL e estruturação de informações.

### 4. Sistema Bancário — Figma
Criação de um protótipo de sistema bancário no Figma, trabalhando na organização das telas e na experiência visual do usuário.

### 5. CRUD em C#
Desenvolvimento de uma aplicação utilizando operações CRUD:

- Create — Criar registros.
- Read — Consultar registros.
- Update — Atualizar registros.
- Delete — Excluir registros.

## 📩 Funcionalidades do formulário de contato

O formulário foi desenvolvido utilizando JavaScript e possui validações para garantir o preenchimento correto dos campos.

Funcionalidades implementadas:

- Validação do nome.
- Validação do endereço de e-mail.
- Validação do assunto.
- Validação da mensagem.
- Exigência de pelo menos 10 caracteres na mensagem.
- Exibição de mensagens de erro.
- Integração com WhatsApp utilizando `window.open()`.
- Preenchimento automático da mensagem com os dados informados.
- Codificação dos textos com `encodeURIComponent()`.
- Integração com e-mail utilizando `mailto:`.

## 📱 Responsividade
