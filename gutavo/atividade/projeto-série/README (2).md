# Love, Death + Robots

Página web desenvolvida como atividade acadêmica, apresentando a série **Love, Death + Robots** com HTML5 e Bootstrap 5.

## Sobre o projeto

O site apresenta informações gerais sobre a série, sua proposta antológica e alguns episódios em destaque. O layout utiliza uma identidade visual inspirada em ficção científica, com cores escuras, detalhes em roxo e rosa e imagens temáticas.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3 via CDN
- Bootstrap Icons via CDN

## Funcionalidades e componentes

- Estrutura com HTML semântico: `header`, `nav`, `main`, `section`, `article` e `footer`.
- Layout responsivo com o sistema de grid do Bootstrap.
- Breadcrumb para indicar a localização do usuário na página.
- Cards do Bootstrap com episódios em destaque.
- Carousel do Bootstrap com três slides, indicadores e controles de navegação.
- Seções com sinopse, ficha técnica e motivos para assistir.
- Link externo para a página da série na Netflix.

## Estrutura de arquivos

```text
atividade-serie/

```

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Mantenha a conexão com a internet ativa para carregar o Bootstrap, os ícones e as imagens externas.

Não é necessário instalar dependências ou executar comandos no terminal.

## Observações

- As imagens são carregadas de endereços externos e dependem de conexão com a internet.
- O conteúdo é informativo e foi produzido para fins educacionais.
- `Love, Death + Robots` é uma série da Netflix. Este projeto não é oficial e não possui vínculo com a plataforma ou com os criadores da série.
